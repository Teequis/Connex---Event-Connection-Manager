# Installation

## Install in Roblox Studio

1. Copy [`Connex.lua`](https://github.com/Teequis/Connex---Event-Connection-Manager/blob/main/Connex.lua) into a ModuleScript named `Connex`.
2. Place it in `ReplicatedStorage` if both client and server scripts need access.
3. Require it from your script. Client and server runtimes have separate module state and caches.

There is no package-manager installation manifest in the reviewed repository.

Continue with [Quick Start](quick-start.md).
