# Connex---Event-Connection-Manager
Connex extends Roblox’s native RBXScriptSignal connections with priorities, named listeners, asynchronous callbacks, automatic cleanup, and shared or independent wrappers, while keeping event management simple.


## Documentation

[Read the documentation](https://teequis.github.io/Connex---Event-Connection-Manager/) for installation, API reference, execution behavior, lifecycle caveats, examples, and benchmark methodology.

To preview locally, install `requirements-docs.txt` and run `python -m mkdocs serve`. See [documentation maintenance](docs/contributing.md) for validation and GitHub Pages setup.
